# Muslim Plus (Quran Kareem)

A free Android app: Quran recitations (streaming and offline download), a page-by-page Mushaf, prayer times and adhan, Qibla, adhkar. No sign-in. No ads.

Download the latest APK: https://github.com/wsalahe/Quran-kareem/releases/download/app-latest/QuranKareem.apk

## Sources and credits

The app does not show a sources screen. The credits for the third-party material it uses are kept here.

- **Quran text, page and juz data:** [Tanzil.net](https://tanzil.net), Uthmani text, licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/). The text is used unmodified.
- **City list (offline location search):** [GeoNames](https://www.geonames.org), cities with more than 15,000 people, licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
- **Full-surah recitations (streaming and download):** the [mp3quran.net](https://www.mp3quran.net) audio library. Recitation rights belong to the reciters and publishers.
- **Ayah-by-ayah audio in the Mushaf:** [everyayah.com](https://everyayah.com).
- **Fonts:** Amiri and Amiri Quran, [SIL Open Font License](https://openfontlicense.org).
- **Adhan audio:** recordings from archive.org (Public Domain Mark).
- **Prayer times:** calculated on the device (the `adhan` library) with the calculation method for the user's country.

## Build

Built by GitHub Actions (Flutter 3.27). The signed APK is published to the `app-latest` release.

## Languages

Arabic (default, the only language with the original Quran, adhkar and AI answers), English, French, Russian, Italian, Chinese, Korean, Japanese. Interface strings for languages other than Arabic and English are machine-written and may contain mistakes. The Quran text, adhkar and AI answers always stay in Arabic.
